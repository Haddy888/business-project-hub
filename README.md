## Important scope note

This hub is the **index**, not a claim that every project is already stored here. A project is marked **GitHub verified** only after its repository contents have been inspected. Projects known from planning and prior work but not yet confirmed in a repository are marked **needs repository verification**.

## Indexing rules

1. Preserve original repositories and commit history; do not overwrite or consolidate project source without a deliberate migration.
2. Record the canonical repository URL, default branch, latest inspected commit, and inventory date.
3. Distinguish committed source from conversation drafts, local files, generated exports, and planned work.
4. Never commit credentials, access tokens, private keys, production secrets, or personal sensitive data.
5. For consequential production changes, follow the project's governance and approval requirements.
